本を読んでも要点が残らない、調べたことをまた検索してしまう、名前が覚えられない。こうした悩みの原因は記憶力ではなく、記憶の出口を使っていないことにあります。読む・見る・聞くは入り口であり、思い出す・書く・話すが出口です。脳は入れた回数ではなく取り出した回数で情報を残すかどうかを決めています。本を閉じて3つ思い出す、検索前に自分のメモを探す、その日・翌日・1週間後の3回に分けて思い出すなど、7つの習慣はすべて出口を通すための工夫です。

はじめに

  • 📌 記憶力の差ではない 本を一冊読んで線も引いたのに、数日後に「どんな本だった」と聞かれて出てくるのは「なんかいい本だった」だけ。昨日調べたことを今日また同じ言葉で検索し、研修でメモまで取ったのに翌日には綺麗に消えている。一方で、同じ本を読んで要点を三つすらすらあげられる人がいます。かけた時間はほとんど変わりません。
  • 📌 原因はたった一つ この差は記憶力の差でも、頭が悪いからでも、集中力が足りないからでも、年のせいでもありません。原因は記憶の出口を使っていないことです。
  • 📌 入り口と出口 読む・見る・聞くは全部記憶の入り口です。思い出す・書く・話すが出口です。どれだけ入り口を広げても、出口を通していないものは残りません。この出口は何歳からでも開けられます。
  • 📌 これからの内容 出口を開ける習慣を七つに絞ってお話ししていきます。

◆ 覚えられないのは覚え方が逆だから ◆

覚えられないのは覚え方が逆だから

  • 📌 心当たりの確認 本を読み終えたのに人に内容を説明できない。読んでいる途中で前の章に何が書いてあったか思い出せない。一度調べたはずのことをまた最初から調べ直している。動画を見て勉強した気になっている。資格のテキストの同じページを三回読んでいる。ノートを綺麗にまとめたのに中身が入っていない。しかもそのノート、二度と開いていない。会議で意見を言おうとして、あれだけ調べたはずのことが出てこない。人に説明しようとすると言葉が詰まる。名前と顔が一致しない。覚えたはずの言葉が一番必要な時だけ出てこない。半分以上当てはまる人もたくさんいます。
  • 📌 よくある誤解 こういうことが続くと、多くの人は「自分は物覚えが悪い」「年のせいかもしれない」「だから人より時間をかけないといけない」と考えます。ところがこの結論には大きな誤解があります。時間をかけてもやり方が同じなら結果はほとんど変わりません。
  • 📌 入り口の作業とは 私たちは覚えようとする時、決まって同じことをします。もう一回読む、もう一回見る。教科書に線を引く。ノートに綺麗にまとめる。動画を見返す。どれも入り口であるインプットの作業です。外にある情報を頭の中に入れようとしています。
  • 📌 出口の作業とは 出口は、頭の中から外に出すアウトプットの作業です。何も見ないで思い出す。人に説明する。紙に書き出す。声に出して言ってみる。そして脳は、入り口を通った回数ではなく、出口を通った回数でその情報を残すかどうかを決めています。
  • 📌 脳の選別基準 そもそも脳は、入ってきた情報を全部保存するようには作られていません。一日に目に入るものを全て覚えていたら、頭がすぐにいっぱいになってしまいます。だから脳は何を残し、何を捨てるかを常に判断しています。大きな基準の一つが、後で必要になったかどうかです。一度しまい込んでその後一回も取り出さなかった情報は必要のないものと判断されます。逆に何度も取り出した情報は、また必要になると判断されて、取り出しやすい場所に移されます。つまり残るかどうかを決めているのは、入れた回数ではなく取り出した回数です。
  • 📌 七つの習慣は同じ原因に向き合う これから紹介する七つの習慣は、バラバラの技を七つ並べたものではありません。原因は一つ、出口を使っていないことだけ。七つの習慣はどれも、この同じ原因に別の場面から聞くようにできています。だから全部を一度に身につける必要はありません。どれか一つが習慣になれば、出口を通すという同じ動きなので、他の場面も一緒に楽になっていきます。
  • 📌 ローディガーの実験 ワシントン大学セントルイス校のヘンリー・ローディガーという研究者が、学生を二つのグループに分けました。片方には同じ文章を何度も読み返してもらう。もう片方には一回読んだ後、本を閉じて内容を思い出してもらう。読み返したグループの方が直後の自信はずっと高かったそうです。ところが一週間後に確認すると結果は逆でした。思い出す練習をしたグループは六割ほど覚えていたのに対して、何度も読み返したグループは四割ほどしか残っていなかったのです。同じ時間をかけて、これだけの差がつきました。しかも自信があったのは、成績が悪かった方でした。
  • 📌 気持ちよさの落とし穴 読み返したグループの方が自信は高かったのですから、安心できるという意味では読み返しはちゃんと効いています。問題は、その安心が当たっていなかったという一点だけです。読み返すのは気持ちがいい。すらすら読めるので分かっている感じがします。一方、思い出す作業は苦しい。出てこない部分にぶつかるので、できていない感じがします。だから私たちは気持ちのいい方を選び続けます。そして、覚えた気になったのに実際には残っていないという状態になるのです。
  • 📌 読んだ量と残る量は別 十冊読んで何も残らないより、三冊読んで要点が残る方が、実際に使える知識は多くなります。しかも出口を通す時間は一章あたり三十秒ほど。読む時間が半分になるわけではありません。

◆ 習慣1 読んだら3つ思い出す ◆

習慣1 読んだら3つ思い出す

  • 📌 読書が入れるだけになりやすい理由 本を読んでいる間は確かに面白かった。頷きながら読んでいた。ところが読み終えて数日経ち、人にどんな話だったと聞かれると、出てくるのは「なんかいい本だった」くらいです。読んでいる途中でも前の章に何が書いてあったか思い出せないことがあります。これは頭が悪いのではありません。読書という行為が、そもそも入れるだけの作業になりやすいからです。文字を目で追っている間、脳は理解はしています。でも、理解することと、後から取り出せるようにすることは、全く別の作業です。しかも本は親切に説明してくれます。次のページをめくれば答えが書いてある。だから自分の頭で思い出す機会が一度もないまま最後まで行ってしまいます。
  • 📌 やることは一つだけ 要点を三つすらすらあげられる人が特別なことをしているわけではありません。読み終えた後に本を閉じて、三つあげてみた。ただそれだけです。一つの章を読み終えたら、本を閉じて内容を三つ思い出してください。紙に書いてもいいし、頭の中でも構いません。大事なのは、本を見ないでやることです。見ながらやったら、それは思い出す作業になりません。
  • 📌 出てこない感覚こそが効く やってみると大抵驚きます。三つ目が出てこないのです。さっき読んだばかりなのに。でもその出てこない感覚こそが効いています。出てこない部分を探して、脳が必ず引っ張り出そうとする。その負荷が記憶を強くします。これが出口を一回通すということです。本を閉じた瞬間、頭の中は入り口から出口に切り替わります。たった三十秒で構いません。一つの章につき三十秒。出口を開けるだけで、その章は読みっぱなしの章とはまるで違うものになります。
  • 📌 読む速さより止まる回数 読書に慣れている人ほど、この三十秒を惜しみます。次のページに進みたいからです。でも、進んだ分だけ残るのではなく、止まった回数だけ残ります。早く読めば多く覚えられるというものではありません。むしろ、思い出す時間を取らずに次のページへ進む方が、残る量は減ります。一冊を早く読み切って何も残らないのと、半分しか読まずに要点が三つ残るのとでは、後者の方がずっと得です。
  • 📌 読み終えたら誰かに話す 家族でも同僚でも独り言でも構いません。人に説明しようとすると、自分が分かっていない部分がはっきり分かります。しかも話すという行為は、思い出す作業そのものです。面白い本の話を人にした記憶は、何年も残っていることがあります。それは偶然ではありません。
  • 📌 本だけではない 動画を見終わったら画面を閉じて三つ。研修が終わったら会場を出る前に三つ。資料に目を通したらファイルを閉じて三つ。何かを閉じるたびに三つ思い出す。閉じるという動作を、出口を開ける合図にしてしまうのです。

◆ 習慣2 検索したことをメモに残す ◆

習慣2 検索したことをメモに残す

  • 📌 検索が残りにくい理由 仕事で分からないことが出てきて検索する。出てきた説明を読んでなるほどと思って仕事に戻る。ところが翌日、同じ場面で同じこと、同じ言葉で検索している。検索という行為は、記憶にとって一番残りにくい形をしています。理由は二つあります。一つは、答えがすぐ出てくることです。苦労なく手に入った情報は、脳から見てわざわざ覚えておく必要がないものに分類されます。次も検索すれば済むのですから当然です。もう一つは、その情報を一回も取り出していないことです。読んで使って、それで終わり。そもそもしまい込んでもいないので、記憶に残る理由がありません。さらに厄介なのが、検索できることで、覚えている感覚だけが手に入ってしまうことです。調べれば分かると思っていると、頭の中は空っぽなのに知っているつもりになります。
  • 📌 工夫1 一箇所にだけ書き止める 調べたことを一箇所にだけ書き止めます。ノートでもスマホのメモでも何でも構いません。ただし置き場所は一つに決めてください。あちこちに散らばると、次に探す時に検索の方が早くなり、結局また検索することになります。書き方は簡単です。調べた言葉と答えを一行。それだけです。綺麗にまとめる必要はありません。
  • 📌 工夫2 検索の前にメモを探す 次に同じことが起きた時、まず自分のメモを開くことです。これが一番大事です。検索の前に自分のメモを探す。この順番にすると、自分のメモを思い出そうとする作業が入ります。確かどこかに書いたと探すこと自体が、思い出す練習になっています。二回これを繰り返すと、メモを開かなくても答えが出てくるようになります。その時にはもう覚えています。
  • 📌 同じ答えでも通った道が違う 検索して答えを読むのも、自分のメモを探して答えを見つけるのも、たどり着く情報は同じです。残らないのは、入り口しか通っていないからです。画面に出てきた答えを読むのは完全に入り口の作業です。一方、自分のメモを探すという行為は、確かどこかに書いたという記憶を呼び出しているので、出口を通っています。同じ答えにたどり着いても、通った道が違えば残り方も違うのです。
  • 📌 工夫3 その場で一回だけ使う 例えば言葉の意味を調べたなら、その言葉を使って一文書いてみる。手順を調べたなら、メモを見ないで最後まで通してやってみる。調べて終わりにせず、そのまま一回使う。それだけで記憶の残り方がはっきり変わります。使うという行為が出口を通る作業そのものだからです。調べた直後は答えが頭にあるので、この一回はとても楽にできます。一番楽なタイミングで一回だけ通しておく。効率のいい投資です。
  • 📌 仕事にも応用できる 新しいツールの使い方を教わったら、その場で一回自分で操作してみる。手順を聞いただけで席に戻ると、次に使う時には消えています。座った直後の一分が、後で三十分を節約します。教わったその場が一番楽に出口を通せるタイミングです。

◆ 習慣3 まとめは質問の形にする ◆

習慣3 まとめは質問の形にする

  • 📌 綺麗なノートの落とし穴 色を使い分けて、見出しをつけて、図を描いて、綺麗なノートを作る。作っている間は充実感があります。ところが後で見返すと、内容が頭に入っていない。それどころか、そのノートを二度と開かない。テスト前にノート作りで満足してしまったことはありませんか。作ったこと自体は全く無駄ではありません。問題は、作って終わりにしていることの方です。これは努力が足りないのではなく、努力の向き先がずれているだけです。
  • 📌 書き移す作業は記憶の作業ではない まとめるという作業の大半は、書き移すことです。書き移している間、脳は文字の形を追っています。内容を思い出しているわけではありません。手は動いているのに、記憶の作業は起きていないのです。しかも綺麗に出来上がると達成感が出ます。だからこれで覚えたと感じてしまう。これは最初にお話しした落とし穴と全く同じ構造です。
  • 📌 思い出すためのノート ノートを何度も開いて使いこなしている人のノートは、大抵見た目は綺麗ではありません。空だらけだったり、疑問文が並んでいたり、余白に走り書きがあったりします。読むためのノートではなく、思い出すためのノートになっているのです。
  • 📌 工夫1 見出しを質問の形にする 「忘却曲線について」ではなく「忘却曲線とは何か」と書く。「敬語の使い方」ではなく「取引先に使ってはいけない敬語は何か」と書く。質問の形にしておくと、次に開いた時に、答えを見る前に自分で考えることになります。答えが並んでいるノートは読むだけになりますが、質問が並んでいるノートは、開く度に思い出す練習になります。
  • 📌 工夫2 穴空きで書く 大事な言葉のところをあえて空にしておきます。そして次に見る時に、その空を自分で埋めます。埋めようとする瞬間、思い出す作業が起きます。書き移すだけのノートがテストに変わるわけです。
  • 📌 工夫3 線を引いたら一言添える 線を引く作業も、書き移すのと同じで、思い出す作業ではありません。それどころか、線が引いてある場所は次に読む時も目が勝手に止まるので、自分で思い出す機会がかえって減ります。引いた後に一つだけ足してください。ページの端に、なぜそこが大事なのかを短く書くのです。自分の言葉に置き換える作業が入った時、初めて記憶の作業が起きます。
  • 📌 工夫4 まとめる時間を短くする 綺麗さに時間をかけるほど、覚える時間が減ります。まとめは十分で終わらせて、残りの時間を、それを見ないで思い出す練習に使ってください。見た目の悪いノートで覚えている人と、美しいノートで覚えていない人がいたら、前者の方が得です。
  • 📌 記録に出口をつける この四つに共通しているのは、記録に出口をつけているということです。普通のノートは入り口しかありません。開いても答えが目に入るだけ。質問の形にしたり、穴空きにしたりすると、開くたびに出口を通ることになります。会議のメモも、仕事の手順書も、スマホに残した走り書きも、同じように作り替えられます。まとめの目的を、綺麗に残すことから、後の自分に思い出させることに変える。それがこの習慣の中身です。
  • 📌 後半のテーマ ここから先は、覚えたはずのものを本番で取り出す習慣の話に入ります。なぜよりによって本番の時だけ出てこないのか。この仕組みを知らないままやり方だけ真似ても続かないからです。前半の三つは、入れ方を出口向きに変える話でした。後半は、入れたものを取り出す力と、それを保つ力の話に入ります。

◆ 習慣4 白紙に書き出して説明する ◆

習慣4 白紙に書き出して説明する

  • 📌 知っているのに出てこない理由 資格の勉強をしていて、テキストを読んでいる時は分かっている。ところが問題を解こうとすると手が止まる。会議で意見を言おうとして、あれだけ調べたのに言葉が出てこない。人の名前も、顔を見た瞬間には出てこないのに、その人が去った後に思い出す。これは覚えていないのではありません。取り出す練習をしていないだけです。
  • 📌 しまう作業と取り出す作業 記憶には、しまう作業と取り出す作業の二つがあります。読んで理解するのはしまう作業です。一方で、必要な時にすっと出てくるかどうかは、取り出す作業の練習量で決まります。例えるなら、道具を買って棚にしまっただけの状態です。買ったことは覚えている。でもどの棚のどこにあるかは、使ってみないと身につきません。
  • 📌 緊張という負荷 本番には緊張があります。緊張している時、脳は普段より取り出しにくくなります。ですから、余裕のある時に取り出せる程度では足りません。何度も通して出口を広げておく必要があります。面接や発表の前に頭が真っ白になった経験は、多くの人にあると思います。あれは覚えていなかったのではありません。狭い出口に緊張という負荷がかかって、通れなくなっただけです。
